# Contributing

Thanks for wanting to help! Bug reports, ideas and pull requests are welcome.

## Ground rules

- **Offline only.** The app must never connect to the internet: no network code, no web views that load remote content, no analytics.
- **No third-party dependencies.** Apple frameworks only.
- **Keep the rules written down.** How files are read and searched is described in [SPEC.md](SPEC.md); change it together with the code. Visual changes start in [docs/ui-spec.md](docs/ui-spec.md).
- **Tests must pass** (`swift test`). A change to how files are read comes with a test file in `Fixtures/` (generated by `scripts/make-fixtures.swift`, with invented text — never real stories) and its expected result.

## Reporting a file that is read wrongly

Please don't attach the fanfic itself. Copy the lines from its first page around `Fandom:`, `Relationship:` and `Characters:` into the issue, and say whether it is an EPUB or a PDF and where it was downloaded.

## Pull requests

1. Fork, create a branch, make the change.
2. Run `swift test` and `./scripts/build-app.sh`, and try the change in the app.
3. Describe what changed and why; include screenshots for visual changes.
